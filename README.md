# iLoveWord — support site

Support, privacy and contact pages for the **iLoveWord — DOCX Tools** app by Alastic. Static HTML served by GitHub Pages.

| Page | What it is |
|---|---|
| `index.html` | Support / help |
| `privacy.html` | Privacy policy (incl. data deletion steps for Google Play) |
| `contact.html` → `thanks.html` | Contact form and confirmation |
| `samples/` | Sample .docx files used in the app's help |
| `style.css` | Shared styles |

Edit a page and push to `main`; GitHub Pages republishes in about a minute. Contact: contact@alastic.id
